# Unity project

Open this `Unity` folder from Unity Hub (Unity 2022.3 LTS). After the editor imports scripts, choose **Sniper Online > Create Desert Test Scene**. The menu creates `Assets/Scenes/DesertTest.unity`; open it and press Play.

The current prototype generates a 4 km x 4 km procedural desert, three simple rock-cover props, a directional sun, and a basic first-person test controller. This is a local prototype only: online matchmaking, account login, weapon models, aiming optics, and authoritative multiplayer are not implemented yet.
