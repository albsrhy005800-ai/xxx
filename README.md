# Sniper Online

مشروع لعبة قناص ثلاثية الأبعاد للأندرويد، بنمط مواجهة لاعب ضد لاعب عبر الإنترنت.

## الرؤية المعتمدة
- المنصة: Android.
- المحرك: Unity 3D مع C#.
- نمط اللعب: 1v1 أونلاين ضد لاعب حقيقي.
- الخريطة الأولى: صحراء بمساحة تصميمية 4 × 4 كم (16 كم²).
- مسافات المواجهة المستهدفة: 500 إلى 1500 متر وأكثر.
- الحسابات: دخول كضيف أو عبر Google.
- المناظير المخطط لها: 4x و8x و15x.

## حالة المشروع
هذه بنية أولية ووثائق وعقود برمجية. لم تُدمج بعد حزم Unity أو Firebase أو خدمة اللعب الجماعي، ولم يُنتج APK بعد.

## البنية
- `Unity/Assets/Scripts/Core`: نماذج الحسابات والمطابقة.
- `Unity/Assets/Scripts/Gameplay`: حسابات أولية لمسار المقذوف.
- `Docs`: قرارات التصميم وخطة دمج الخدمات.

## البدء
1. أنشئ مشروع Unity 3D (إصدار LTS حديث).
2. انسخ مجلد `Unity/Assets` إلى مشروع Unity.
3. فعّل Firebase Anonymous وGoogle Authentication وأضف إعداد Android محلياً.
4. اختر خدمة Multiplayer حقيقية واربط المطابقة والغرف.
5. اختبر مباراة بين جهازين قبل إصدار APK.

لا تضع مفاتيح سرية أو ملفات اعتماد Firebase في المستودع العام.

## المراحل
1. مشهد محلي للصحراء وحركة اللاعب.
2. سلاح ومنظار وتحكم لمس.
3. حساب ضيف وGoogle وربط الحسابين.
4. مطابقة 1v1 وغرفة لعب.
5. اختبار جهازين وشبكات مختلفة.
6. تحسين الأداء وبناء APK موقّع.
